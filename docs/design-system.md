# Nutrigon Design System

Design tokens and guidelines derived from the official brand logo (`nutrigonLogo.jpeg`).

## 1. Brand Identity

- **Brand Name:** Nutrigon
- **Tagline:** Dietética
- **Symbol:** Golden wheat grain within a circular seal
- **Visual Style:** Organic, conscious health store, warm, grounded, and clean.

## 2. Color Palette

| Token                                       | Hex Value   | Usage                                                  | Reference                  |
| :------------------------------------------ | :---------- | :----------------------------------------------------- | :------------------------- |
| **Primary (Wheat Gold)**              | `#F5B731` | Brand accents, key CTAs, active indicators, highlights | Logo wheat ear & rings     |
| **Secondary (Roasted Grain / Amber)** | `#E59F18` | Hover states, secondary accents, badges                | Logo gradient / warm grain |
| **Tertiary (Warm Stone)**             | `#78716C` | Borders, subtle dividers, secondary text               | Earthy grounding tone      |
| **Neutral Dark (Ink Charcoal)**       | `#121316` | Dark mode background, primary surface                  | Logo lettering ink         |
| **Neutral Dark Surface**              | `#1C1E24` | Elevated cards, dialogs, inputs                        | Dark container elevation   |
| **Neutral Light (Cream Off-White)**   | `#FDFDFD` | High-contrast primary text on dark theme               | Crisp legible text         |

## 3. Typography

- **Display / Subtitle (Brand Headings):** `Outfit` (Geometric modern sans-serif matching the "Dietetica & Cerealera" circular curve).
- **Body & Interface (UI & Data):** `Plus Jakarta Sans` (Clear legible text for weights, nutritional tables, prices, and buttons).
- **Lettering (Logo Display Only):** Brush script calligraphic lettering (used only for the main logo mark).

## 4. Shapes & Spacing

- **Corner Radius:** `ROUND_EIGHT` (`rounded-lg` / 8px) for cards, chips, and modals.
- **Button Targets:** Minimum touch height `44px` (`min-h-[44px]`).
- **Layout:** Mobile-first fluid grid, expanding to multi-column on desktop (`md:` / `lg:`).
